## How to regenerate

```bash
cd tender-submission/build
node diagrams.js          # figures (needs Chrome)
node build.js             # documents 01-05 and 08 (.docx)
# deck: NODE_PATH=./node_modules PPTX_SKILL=<pptx skill dir> node deck.js && python letterhead-deck.py
```

Then export PDFs with Word / PowerPoint into `tender-submission/PDF's/` and copy the files here.
